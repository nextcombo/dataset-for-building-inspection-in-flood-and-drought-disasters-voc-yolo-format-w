# Dataset for Building Inspection in Flood and Drought Disasters - VOC+YOLO format with 9464 images in 3 categories

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 9464

Number of annotations (number of xml files): 9464

Number of annotations (number of txt files): 9464

Label category count: 3

Label category names (Note that the order of categories in the Yolo format does not correspond to this, but is based on the classes.txt file in the labels folder): ["house", "person", "vehicle"]

Number of boxes labeled in each category:

House frame count = 19193

Person Frames = 20205

Number of vehicle frames = 19667

Total frames: 59065

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: No

Special : This dataset does not guarantee the accuracy or precision of the trained models or weight files. The dataset is provided with accurate and reasonable annotations only.
